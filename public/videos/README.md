# Carpeta de videos

Subí acá los 6 videos de cada integrante tocando, con estos nombres exactos:

- `integrante-1.mp4`
- `integrante-2.mp4`
- `integrante-3.mp4`
- `integrante-4.mp4`
- `integrante-5.mp4`
- `integrante-6.mp4`

Formato recomendado: `.mp4` (H.264), relación de aspecto cuadrada (1:1) para que se vean bien en la grilla, sin audio o con audio silenciado (se reproducen en loop y muteados automáticamente).

Si querés usar otro nombre por integrante, avisame y actualizo las referencias en `src/components/VideoGrid.tsx`.
